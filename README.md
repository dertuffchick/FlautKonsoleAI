# FlautKonsoleAI

# Краткий гайд на установку. #
1. сначала в консоли стандартно делаем  git clone https://github.com/dertuff/FlautKonsoleAI.git или напрямую из браузера скачиваем - https://github.com/dertuff/FlautKonsoleAI.git
2. затем проверяем установлен ли python на устройстве командой python --version в консоли(если все хорошо - то будет Python 3.11.5 (tags/v3.11.5:cce6ba9, Aug 24 2023, 14:38:34) [MSC v.1936 64 bit (AMD64)] on win32
Type "help", "copyright", "credits" or "license" for more information.)  
*1 если все хорошо, то переходим к пункту 3  
*2 если все плохо с python то это плохо и скачиваем и запускаем https://drive.google.com/file/d/1L1HDtpf9UzsaBtDlm4V3mqYb2GgF0kvS/view?usp=sharing, после чего перезагружаем терминал  
3. если все хорошо, то выполняем команду в терминале
*pip3 install requests colorama pygments pyreadline3
4. теперь запускаем flaut_ai_final.py и можно пользоваться.
# P.S. Инструкция настроенна на пользователя системы Windows, т.к. проект FlautKonsoleAI изначально создавался для использования узким кругом людей, которые пользуются Windows.#
